# onepress-deck-video — ClawHub Skill

A ClawHub/OpenClaw skill that delegates deck-video production to [OnePress](https://www.getonepress.com).

**Requires `ONEPRESS_API_KEY`** — deck-video synthesis runs on OnePress infrastructure.
Create a key at getonepress.com → app → Settings → Account → API keys.

See `SKILL.md` for the full contract (REST + MCP, polling, follow-ups, errors).

```bash
clawhub install onepress-deck-video
```
